## Batas bukti offline dan penyimpanan

Skenario offline memakai browser context offline=true sejak sebelum pemuatan aplikasi. Aset produksi dilayani dari file lokal oleh Playwright; binding pengujian menjalankan core Rust dan SQLite melalui proses lokal untuk setiap perintah. Tidak memakai HTTP RPC untuk skenario offline. Tidak ada permintaan eksternal teramati. Adaptor tidak dikemas ke aplikasi. Skenario lain masih memakai HTTP loopback khusus tes.

Ini menguji frontend dan backend nyata tanpa akses jaringan browser, tetapi belum membuktikan IPC Tauri/WebView2, installer Windows, atau persistensi setelah penutupan native Windows. Host Tauri mengarah ke app_data_dir()/ardin-saham.db, umumnya %APPDATA%\id.ardin.saham\ardin-saham.db. Database tes terpisah dari data pengguna. Tidak ada koneksi layanan eksternal dalam kode runtime src/, core/src/, src-tauri/src/ yang diperiksa. CSP membatasi koneksi ke IPC lokal.

## Hambatan dan pekerjaan tersisa

1. Build Windows yang dicoba: npm run tauri -- build --target x86_64-pc-windows-msvc --bundles nsis -- --locked. Berhenti karena target Windows tidak terpasang; hanya target Linux tersedia. Toolchain MSVC/Windows SDK dan runner Windows tidak tersedia pada lingkungan ini. Installer .exe **belum dihasilkan**.
2. gh auth status gagal: token GitHub yang disediakan lingkungan tidak valid. GitHub Actions belum dapat dijalankan melalui CLI. Status push dicatat pada laporan akhir sesi.
3. TP belum memiliki pengaitan transaksi penjualan ke target, baseline per siklus, atau konfirmasi eksekusi target. Perubahan status harga tidak mengurangi posisi. Rencana lama masih perlu ditinjau ulang setelah averaging atau pembukaan siklus baru.
4. Fitur terdahulu yang hilang memerlukan sumber branch/commit asli untuk rekonsiliasi. Tidak ada klaim seluruh pengembangan terdahulu tersimpan di GitHub.
5. Masih diperlukan pengujian Windows install/uninstall/update, buka tanpa jaringan, transaksi, tutup/buka aplikasi, backup/restore. Build berhasil saja tidak cukup untuk menyatakan siap digunakan.
